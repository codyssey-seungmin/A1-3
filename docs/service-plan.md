# 서비스 기획서: 오늘의 책, AI 사서

## 1. 서비스 개요
- **서비스명**: 오늘의 책, AI 사서
- **목적**: 책을 읽고 싶지만 무엇을 읽을지 정하지 못하는 사람에게, 오늘의 기분·취향·가용 시간에 맞춘 책 3권을 즉시 추천한다.
- **타겟 사용자**: 독서를 시작하고 싶지만 책 선택에 어려움을 느끼는 20~30대, 자투리 시간에 짧게라도 읽고 싶은 직장인/학생.

## 2. 페이지/섹션 구성
| 페이지 | 파일 | 설명 |
|---|---|---|
| 홈 | index.html | 서비스 한 줄 소개, 핵심 가치 3가지, AI 추천 페이지로 유도 |
| AI 책 추천 | recommend.html | 핵심 기능. 기분/장르/시간 입력 → AI 추천 결과 출력 |
| 소개 | about.html | 서비스 목적, 타겟, 이용 방법 3단계 안내 |
| FAQ | faq.html | 자주 묻는 질문 4가지 (동작 원리, 데이터 저장 여부, 오류 대응, 신뢰성) |

네비게이션은 모든 페이지 상단 헤더에 고정 노출되며, 모바일에서는 햄버거 버튼으로 열고 닫는다.

## 3. 핵심 기능 (AI 기능 설계)
- **입력**
  - 기분 (select: 기쁨/우울/편안/설렘/무기력)
  - 좋아하는 장르/소재 (자유 텍스트)
  - 오늘 읽을 수 있는 시간 (select: 10분 이내/30분 정도/1시간 이상)
- **처리**: 프론트엔드가 `fetch('/api/recommend')`로 입력값을 백엔드에 전달 → 백엔드(Vercel Serverless Function, Python)가 Anthropic Claude API를 호출해 조건에 맞는 책 3권과 추천 이유를 생성 → JSON으로 프론트에 반환.
- **출력**: 책 제목, 저자, 추천 이유(2문장 이내)로 구성된 카드 3개.
- **제공 가치**: 선택 피로를 줄이고, 근거(이유)가 있는 추천으로 신뢰도를 높인다.

## 4. 실패 처리 기준
| 상황 | 감지 위치 | 사용자 안내 |
|---|---|---|
| 빈 입력(필수값 누락) | 프론트(js/recommend.js) 및 백엔드(api/recommend.py) 이중 검증 | "모든 항목을 입력해주세요." |
| API 오류 (4xx/5xx) | 프론트: response.ok 확인 | "일시적인 오류가 발생했습니다. 잠시 후 다시 시도해주세요." |
| 응답 지연/타임아웃 | 프론트: AbortController로 15초 제한 | "응답이 지연되고 있어요. 잠시 후 다시 시도해주세요." |

## 5. 기술 스택
- 프론트엔드: 바닐라 HTML / CSS / JavaScript (프레임워크 미사용)
- 백엔드: Vercel Serverless Functions (Python), Anthropic Claude API
- 배포: GitHub + Vercel (GitHub 저장소를 Vercel과 연동해 push 시 자동 배포)
